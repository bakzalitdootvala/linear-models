# Настройка окружения

[English](../en/setup.md) · **Русский**

> Как запустить проект и что делают проверки.

## Требования

- git
- [uv](https://docs.astral.sh/uv/), он же ставит Python 3.12, если его нет

## Установка

```bash
uv sync
```

Команда создаёт `.venv` и ставит рабочие и dev-зависимости ровно в тех версиях, что записаны в `uv.lock`.

## Запуск проверок вручную

```bash
uv run pytest
uv run mypy
uv run ruff check .
uv run ruff format --check .
```

## Pre-commit-хуки

```bash
uv run pre-commit install
uv run pre-commit run --all-files
```

Хуки запускаются перед каждым коммитом:

- `ruff-check` и `ruff-format`: линтер и форматирование.
- `pre-commit-hooks`: хвостовые пробелы, конец файла, окончания строк, синтаксис YAML, TOML и JSON, маркеры merge-конфликтов, конфликты регистра в именах файлов, симлинки, приватные ключи, файлы больше 512 КБ.
- `nbstripout`: убирает из ноутбуков счётчики запусков и метаданные, выводы оставляет.
- `gitleaks`: ищет секреты в изменениях, которые идут в коммит.
- `markdownlint`: стиль Markdown.
- `mypy`: строгая проверка типов в окружении проекта.
- `ru-en-parity` и `relative-links`: английская и русская документация зеркальны, а относительные ссылки ведут на существующие файлы и заголовки.

Хуки закреплены по SHA коммита, а тег остаётся в комментарии `# frozen:`: перевешенный на другой код тег хук не подменит. Чтобы обновить хуки, запускают `uv run pre-commit autoupdate --freeze` и читают дифф.

## Ветки

Репозиторий личный, у него один владелец, поэтому вся работа идёт прямо в `main`. Веток `develop`, `fix/*`, `feature/*` и других нет, изменения не проходят через pull request.

## Непрерывная интеграция

`.github/workflows/ci.yml` запускается на каждый push в `main` и на каждый pull request. Задание `pre-commit hooks` гоняет все хуки по всем файлам и сканирует gitleaks всю историю git. Задание `pytest` запускает тесты. Actions закреплены по SHA коммита.

## Зависимости

Рабочую зависимость добавляют командой `uv add <пакет>`, dev-зависимость командой `uv add --group dev <пакет>`. `pyproject.toml` и `uv.lock` коммитятся вместе. Версия ruff в `.pre-commit-config.yaml` должна совпадать с версией в `uv.lock`.

## Документация на двух языках

У каждого файла в `docs/en/` есть пара в `docs/ru/` по тому же пути, и каждый файл в первых строках ссылается на свою пару. `scripts/check_parity.py` падает, если пары нет, ссылки на неё нет или страница не перечислена в оглавлении своего языка.
